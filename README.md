## О проекте
**Многосервисная система анализа перемещений персонала в режиме реального времени** - это распределенная система мониторинга и безопасности для промышленных предприятий, построенная по микросервисной архитектуре.

## Технологический стек
- Backend: Python + FastAPI + Uvicorn
- Базы данных: SQLite (легковесные БД для каждого сервиса)
- Контейнеризация: Docker + Docker Compose
- Научные вычисления: NumPy + SciPy + scikit-learn
- Документация: OpenAPI 3.0 (Swagger)
- Тестирование: pytest

## Быстрый старт
1. Клонирование репозитория
``` bash
git clone <repository-url>
cd lps_micro_clean
```
2. Запуск системы (Docker Compose)
```bash
# Сборка и запуск всех сервисов
sudo docker compose up --build
```
3. Документация API
Откройте в браузере:
- Positioning Service: http://localhost:8001/docs
- Access Control Service: http://localhost:8002/docs
- Data Aggregator Service: http://localhost:8003/docs
- ~~Alert Service: http://localhost:8004/docs~~
- Notification Service: http://localhost:8005/docs

> [!TIP]
>Проект построен на основе python FAST API.
В директории каждого сервиса лежит его openapi спецификация, вы можете ознакомится с ней, либо использовать swagger документацию для быстрого и интерактивного знакомства с функционалом.

# Идея проекта

### LPS
Система локального позиционирования - программно аппаратный комплекс, состоящий из неподвижных базовых станций (анкеров) и мобильных устройств-меток (тегов).

Базовые станции измеряют расстояния до меток, далее они накапливают их в некотором общем хабе, который передает их на сервер для обработки.

Обработка заключается в том, что зная расстояния от, как минимум, трех пространственно разнесенных точек до некой четвертой, а также координаты всех этих трех точек, мы можем восстановить координаты четвертой. Алгоритм для восстановления называется трилатерация.

В данной реализации применен более совершенный и вычислительно сложный подход, а именно задача трилатерации заменена задачей минимизации ошибки.
Такой подход может применяться только на стационарных серверах, но никак не в embeded устройствах, а это как раз наш случай.

### интеграция на производстве

Система, способная с сантиметровой точностью отслеживать перемещения объектов, отлично подходит для интеграции в опасные производства. Разработанный набор микросервисов поможет вам реализовать систему мониторинга и безопасности. Вы можете внести зоны на вашем предприятии, после можете настроить правила нахождения сотрудников в той или иной зоне (_длительность / кому можно, а кому нет ..._). Также реализован сервис агрегации данных, который поможет вам в аналитике, не только с точки зрения безопасности, но также и оптимизации. Предоставлен каркас для реализации системы оповещения ответственных лиц при помощи разных каналов связи.
