### Сборка и запуск

Используется docker compose
просто в корне проекта выполните:
``` bash
sudo docker compose up --build
```

После этого микросервисы будут запущены в отдельных докер контейнерах.
Порты для localhost:
8001-8005
### Тестирование
В проекте используется pytest. Для запуска:
``` bash
pytest ./access_control_service/tests/ -v
```
### Знакомство с функционалом

Проект построен на основе python FAST API.
В директории каждого сервиса лежит его openapi спецификация, вы можете ознакомится с ней, либо использовать swagger документацию для быстрого и интерактивного знакомства с функционалом.

Откройте веб-браузер, введите адрес интересующего вас микросервиса. Откроется страничка с его swagger документацией. Тут вы можете экспериментировать и проверить свои идеи.


### Идея проекта

#### LPS
Система локального позиционирования - программно аппаратный комплекс, состоящий из неподвижных базовых станций (анкеров) и мобильных устройств-меток (тегов).

Базовые станции измеряют расстояния до меток, далее они накапливают их в некотором общем хабе, который передает их на сервер для обработки.

Обработка заключается в том, что зная расстояния от, как минимум, трех пространственно разнесенных точек до некой четвертой, а также координаты всех этих трех точек, мы можем восстановить координаты четвертой. Алгоритм для восстановления называется трилатерация.

В данной реализации применен более совершенный и вычислительно сложный подход, а именно задача трилатерации заменена задачей минимизации ошибки.
Такой подход может применяться только на стационарных серверах, но никак не в embeded устройствах, а это как раз наш случай.

##### интеграция на производстве

Система, способная с сантиметровой точностью отслеживать перемещения объектов, отлично подходит для интеграции в опасные производства. Разработанный набор микросервисов поможет вам реализовать систему мониторинга и безопасности. Вы можете внести зоны на вашем предприятии, после можете настроить правила нахождения сотрудников в той или иной зоне (длительность / кому можно, а кому нет ...). Также реализован сервис агрегации данных, который поможет вам в аналитике, не только с точки зрения безопасности, но также и оптимизации. Предоставлен каркас для реализации системы оповещения ответственных лиц при помощи разных каналов связи.
